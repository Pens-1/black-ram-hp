# スプレッドシートでの更新

ライブ・曲・グッズは Google スプレッドシートで更新する。サイトはビルドのたびにシートを読み直す。

- シートの URL・ID は公開リポジトリに載せない。ID は Cloudflare Pages の環境変数 `SHEET_ID` と、手元の `.env`（git に入れない）にだけ置く
- 共有は「リンクを知っている全員が閲覧可」のままにする（閲覧不可にするとサイトが更新されなくなる）

## バンド向け: 更新のしかた

1. シート「ライブ」「曲」「グッズ」に1行1件で書く。見出しの行は消さない・名前を変えない（列の並べ替えは OK）
2. 日付は `2026-10-20` の形。年が分からない古いライブだけ `6/22` でも OK（過去のライブ扱い、年は出ない）
3. 空欄の項目はサイトに出ない。「メモ」列はサイトに出ない
4. 画像は Google ドライブの画像のリンク（共有＝リンクを知っている全員）を貼る
5. メニュー「サイト」→「サイトに反映」を押す。数分でサイトに出る（押し忘れても毎日0時台に自動で反映）

| シート | 必須 | サイトでの出方 |
|---|---|---|
| ライブ | 日付・会場 | 翌日0時（日本時間）より前で一番近いものがトップの NEXT LIVE。終わったものは「過去のライブ」へ新しい順。出演は「/」区切り。「BLACK RAMの出演時間」は空なら出ない。チケットのリンクがあればボタン |
| 曲 | 作品名 | 発売日の新しい順（発売日が空なら上の行ほど新しい扱い、発売日のあるものの後ろ）。先頭が LATEST。サービスのリンクは空でないものだけ。Spotify はアルバムの URL ならその場で聴けるプレーヤーになる |
| グッズ | 商品名 | 名前・値段・サイズ色・写真・「買う」ボタン（リンクがあれば）。売り切れ列に「○」などを入れると SOLD OUT（ボタンは押せない）。値段もリンクもない商品は名前だけ |

必須の列が空、日付の形が違う行は飛ばされる（ビルドのログに「ライブ 5行目: 日付が空 → 飛ばした」のように出る）。

## 仕組み

- `npm run build` の前（`prebuild`）に `scripts/fetch-sheet.mjs` が3シートを CSV で読み、`src/data/sheet/lives.json` `songs.json` `goods.json` に書き出す。`src/data/site.ts` がそれをビルド時の日付で振り分ける
- シート ID は環境変数 `SHEET_ID`（未設定なら取得せず前回の JSON を使う）。取得・読み取りに失敗したシートは、コミット済みの前回の JSON でビルドを続ける
- 画像列: `/img/...` は `public/` の既存の WebP をそのまま使う。Google ドライブのリンクはダウンロードして `public/img/sheet/<ファイルID>.webp`（と一覧用の `-s.webp`）に変換。ファイル ID でキャッシュし、あれば変換し直さない。変換には ffmpeg か python3 + Pillow が要る。失敗したら画像なしで続く
- 手元で読み直すだけ: `npm run sheet`。手元の CSV で試す: `SHEET_CSV_DIR=scripts/test/fixtures SHEET_OUT_DIR=/tmp/out npm run sheet`。テスト: `npm test`

## 「サイトに反映」ボタンの設定（最初に1回）

1. Cloudflare Pages のプロジェクト → Settings → Builds & deployments → Deploy hooks でフックを作り、URL を控える（ビルドコマンドは `npm run build`）
2. シートを開き、拡張機能 → Apps Script
3. `コード.gs` の中身を消して、`scripts/apps-script/Code.gs` を丸ごと貼り付けて保存
4. 左の歯車（プロジェクトの設定）→ タイムゾーンを「(GMT+09:00) 日本標準時」に。下の「スクリプト プロパティ」に `DEPLOY_HOOK_URL` = 1 の URL を追加
5. エディタ上部の関数で `setupDailyTrigger` を選んで実行。権限の確認が出たら許可する（毎日0時台の自動反映ができる）。`Code.gs` の `@OnlyCurrentDoc` で、権限は「このシートだけ」に絞られる。この行は消さない
6. シートを開き直すとメニュー「サイト」が出る。「サイトに反映」を押して「反映を始めました」と出れば完了

- 5分以内にもう一度押しても「さっき反映しました」と出て、何もしない
- 失敗すると「反映できませんでした: …」と出る（URL の未設定・間違いなど）。自動反映の失敗は Google からエラー通知のメールが届く
