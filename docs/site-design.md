## 3. 状態
- 予定ライブ0件（シートに未来のライブがない／次のライブの日付が過ぎた）: 「次のライブは近日発表」とだけ出す（文言は要確認）。判定はビルド時と表示時（JS）の両方で行う
- 埋め込みプレーヤーは押すまで読み込まない。JSなしでは Spotify へのリンクになる
- 動きを減らす設定のとき: 動画は止めて静止画を出す
- 基準はスマホ（幅390）。PC（幅1280）でも崩れないこと

## 4. 技術
- Astro の静的サイト。進め方は web-design-flow に従う
- デプロイ先は未定（指示があるまで公開しない）
- ライブ・曲・グッズはビルド前（`prebuild`）に `scripts/fetch-sheet.mjs` がスプレッドシートから読む。失敗したら前回の JSON（`src/data/sheet/`）で作る。シートの「サイトに反映」（Apps Script → Cloudflare Pages の deploy hook）と毎日1回の自動反映で作り直す（docs/sheet-update.md）
- デモ公開中は noindex（フラグは src/data/seo-config.ts の NOINDEX。robots.txt・X-Robots-Tag・robots meta を一括で切り替える）。正式公開時に外す。SEO・構造化データは docs/seo.md
